# Latihan mandiri pertemuan 1

Folder ini berisi latihan tambahan yang dibuat untuk mendampingi aplikasi tugas. Materi atau file latihan asli dari asisten praktikum tidak disertakan dalam permintaan, sehingga latihan ini bukan salinan atau bukti mengikuti modul asli. Buka `index.html` menggunakan Live Server. Tambahkan hasil latihan resmi Anda ke folder ini jika diwajibkan asisten.
